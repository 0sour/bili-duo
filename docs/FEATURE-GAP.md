# 功能对比与缺口清单（2026-11-13）

> 对照对象：**wiliwili 1.6.0**（本地 `D:\项目\wiliwili-android` 源码核对）、
> bilimiao2、PiliPala、BBLL（仅作功能参考，未逐行核对源码）。
> 本机状态：Bili-Duo `0.2.0-rc55` + 上下屏交换 + 启动器快捷方式（未重新发版）。
>
> 标记：✅ 已有；◐ 部分/有替代路径；— 没有。

## 1. 结论先行

1. **核心观看链路已经不弱于 wiliwili**：推荐/热门/排行/直播/番剧/影视、搜索、
   播放、弹幕、字幕、评论、动态、收藏、历史、下载、投币都齐了；双屏/手柄/
   评论发布/下载/弹幕发送撤回是明显领先项。
2. **真正的差距在「账号内容中心」和「PGC 发现」**，不是播放器：
   - 稍后再看、我的追番/追剧、番剧/影视索引、搜索番剧/影视；
   - 消息中心（回复/@/赞）、私信；
   - PGC 详情页目前没有收藏/追番操作（简介页对 PGC 隐藏了关注/收藏/下载）。
3. **第二梯队**：视频合集（UGC season）在播放器内切换、直播历史弹幕、离线弹幕、
   播放器增强（音轨/连播开关/片头尾/睡眠/PiP）、动态发布转发。
4. 按「一个开发 + 现有架构」估算，P0 全部做完约 **2–3 周**，P1 约 **3–4 周**，
   P2 可按版本穿插。

## 5. 缺口 C：本项目体验 / 收尾（与功能对等无关，但影响发布）

- 亮色下个别图片叠层、第三方 Geetest WebView 仍是深色；按页面截图补 token。
- 少数二级页（搜索/登录/下载等）空态说明仍写死「上屏/下屏」，交换后可读性差。
- 真实手柄长按 repeat、断连/热插拔提示未复测；双屏截图/录屏、冷启动/后台恢复
  回归未做完整一轮。
- 直播真实发送、直播关注写操作需要账号授权复测；真实 SC 样本仍建议补测。
- 非会员画质锁 / 试看结束 / 充电专属视频只有部分验证。
- 单屏直播/PGC 明确不在第一发布版范围（见 AGENTS.md「单屏回退范围」）。
