## 1. 全局壳层

### 1.1 浏览态壳层（有左侧 rail）

```
640×480
┌──────┬────────────────────────────────────────────┐
│ Rail │ AppBar 44dp                                │
│ 64dp ├────────────────────────────────────────────┤
│      │                                            │
│      │ Content 576×408dp                          │
│      │                                            │
│      │                                            │
├──────┴────────────────────────────────────────────┤
│ ModeBar 28dp                                       │
└───────────────────────────────────────────────────┘
```

- Rail：64dp 宽，5 个入口（首页、搜索、历史、收藏、我的）+ 底部设置。
- AppBar：44dp，左标题 `titleL`，右最多 2 个动作。
- Content：576×408dp；列表页自带 12dp 左右内边距。
- ModeBar：28dp，全宽常驻，见 §8。

### 1.2 播放态壳层（无 rail）

进入视频播放后，下屏切换为「播放控制台」，隐藏全局 rail 和 AppBar，把全部
640×452dp 留给播放信息与控制。B 退出播放后恢复浏览态壳层与来源列表。

### 1.3 导航图

```
Home ──→ PlayerConsole(下屏) + Video(上屏)
  │            ├─ Comments
  │            ├─ Related
  │            ├─ Intro（UP 主 + 收藏/下载）
  │            └─ Parts
  ├─ Search ──→ PlayerConsole
  ├─ History ──→ PlayerConsole
  ├─ Favorites ──→ PlayerConsole
  ├─ Downloads ──→ 本地播放
  ├─ Following ──→ Channel
  ├─ Profile ──→ Settings / Login
  └─ Settings
```

- 一级页面（rail 五个）切换时清空该 tab 的返回栈到根。
- Search/Channel/Settings 等是压栈页面；B 逐级返回。
- **没有独立视频详情页**：点击视频卡片直接进入播放，上屏开始播放，下屏进入
  播放控制台；退出播放回到来源列表。
- **上屏预览**：下屏焦点落到视频卡片时，上屏显示“左 2/3 封面 + 右 1/3 标题/
  简介/UP 信息”；焦点离开视频卡或没有选中时显示品牌待机页。预览只读、不可聚焦。
  详见 [`TOP_SCREEN.md`](TOP_SCREEN.md) §3.1。
- PlayerConsole 不是一个可返回的「页面」：它由「上屏是否有视频」决定显示；
  B 的语义是退出播放（先关 overlay，再确认，再退出）。

### 3.2 规格

- 3 列网格；卡片 178.7×158dp；缩略图 178.7×100.5dp；标题 2 行 `bodyM`；元信息 1 行 `caption`。
- 首屏可见 2 行完整卡片 + 第三行露出缩略图顶部（提示可滚动）。
- tab 顺序：推荐 / 热门 / 排行 / 番剧 / 影视；左右键在 tab 上直接切换并加载，
  A 也可切换。番剧/影视使用 4 列竖版封面卡，点击直接播放第一集，控制台「选集」
  tab 切集。
- 下拉刷新不适用（无触摸手势要求）；AppBar 右侧 `⟳` 刷新当前 tab。
- 滚动到底自动加载下一页；底部显示 32dp 加载行（三个点）。
- 空态：`还没有内容` + 「换个 tab」；错误态：`加载失败` + 「重试」。
- 进入首页默认聚焦第一个卡片；A 直接播放（无详情页）；从播放退出返回时恢复上次卡片。
- 长按卡片：弹出上下文菜单（稍后再看 / 不感兴趣 / 打开 UP 主），Phase 3。

### 3.3 数据

- 推荐：`x/web-interface/wbi/index/top/feed/rcmd`（WBI）。
- 排行：`x/web-interface/ranking/v2?rid=0&type=all`，固定 top100，无分页。
- 番剧/影视：`pgc/web/rank/list?season_type=1/2` 列表；点击后走
  `pgc/view/web/season` + `pgc/player/web/playurl`，剧集映射为控制台「选集」。
  未登录可播免费集；VIP 集权限待登录验证，不要用 UGC 搜索兜底冒充。
- 每页 20 条；封面统一带 `@` 尺寸后缀，避免拉原图。

### 4.3 输入法策略（关键）

| 输入方式 | 行为 |
|---|---|
| 触摸搜索框 | 请求系统 IME；若 IME 出现在下屏，正常输入 |
| 手柄 A | 聚焦搜索框并请求 IME；同时显示「触摸输入 / 选历史」提示 |
| IME 未出现在下屏 | 降级为**应用内键盘**：全屏 6 行拉丁字母 + 数字，A 输入，Y 删除，X 空格，START 搜索 |
| 中文输入 | 应用内键盘不做拼音；优先让用户选历史词/热门词，或触摸用系统 IME |

风险与验收见 [`INPUT_AND_FOCUS.md`](INPUT_AND_FOCUS.md) §7。实现上先做触摸 + 系统 IME，
应用内键盘作为 Phase 2 的兜底，不要一开始就自研中文输入法。

### 6.2 布局数值

- 外层 12dp 内边距；左栏 **272dp**，间距 12dp，右栏 **332dp**。
- 左栏自上而下：
  - 标题 2 行（44dp）+ UP/数据（20dp）
  - 进度条区（40dp）：时间 44dp + 轨道 + 总时长 44dp
  - 传输按钮行（56dp）：⏮ 40 / ↺10 40 / ▶ 56 / ↻10 40 / ⏭ 40，间距 6dp
  - 状态 chip 行（26dp，紧凑，单行）：`1080P`、`1.0×`、`弹幕 开/关`、`音量 80%`、
    齿轮；只显示当前值，不写「清晰度/倍速」前缀；放不下时横滑，不换行。
    弹幕 chip 激活态用粉色边框，点击即切换开关；齿轮打开「弹幕设置」overlay
    （显示开关/不透明度/速度/字号/显示区域/屏蔽词/同屏上限），A 循环取值，
    屏蔽词进入内嵌编辑态（输入框 + 保存/取消），B 先退出编辑、再按 B 关闭。
  - 剩余空间：播放队列/分P 快捷入口（可选，Phase 3）
- 右栏：tab 36dp + 内容 352dp；tab 固定 4 个，不横滑。
- 底部 ModeBar 28dp 全宽。

### 6.3 两种输入模式下的视觉

| 状态 | 视觉 |
|---|---|
| `TOP_PLAYER`（手柄控播放） | 控制台整体 60% 不透明度；无焦点环；ModeBar 粉点「手柄：播放」；按 Y 或触摸下屏进入 `BOTTOM_UI` |
| `BOTTOM_UI`（手柄控下屏） | 控制台 100%；焦点环出现在「播放/暂停」或上次焦点；ModeBar 蓝点「手柄：下屏」 |
| overlay 打开 | 控制台压暗 40%，overlay 100%；焦点陷阱在 overlay；ModeBar 显示「B 关闭」 |

- 首次进入播放：默认 `TOP_PLAYER`；下屏显示控制台但不高亮任何控件，避免与上屏抢注意力。
- 播放中按 A：播放/暂停；按 B：退出确认（若正在播放则先暂停并弹确认）。
- 按 Y：切到 `BOTTOM_UI`；再按 Y 回 `TOP_PLAYER`。
- 触摸下屏任意位置：切到 `BOTTOM_UI`；**第一次触摸只切模式 + 聚焦被触摸项，不触发点击**（防止误操作）。
- 暂停时：默认仍留在 `TOP_PLAYER`，画面冻结；下屏控制台显示「已暂停」。

### 6.4 传输按钮映射

| 按钮 | 手柄 | 行为 |
|---|---|---|
| ⏮ | LB | 上一个分P；没有则回到开头 |
| ↺10 | ← / LT? | 后退 10s（长按连续） |
| ▶/⏸ | A | 播放/暂停 |
| ↻10 | → | 前进 10s |
| ⏭ | RB | 下一个分P |
| 清晰度 | START | 打开右侧清晰度 sheet |
| 倍速 | LT/RT | 0.5×–2.0× 循环；长按连续 |
| 弹幕 | X | 开关弹幕 |
| 音量 | ↑/↓ | 音量 ±5%；HUD 1.5s |
| 更多 | BACK | 打开更多 sheet |

> 键位以实现文档 [`INPUT_AND_FOCUS.md`](INPUT_AND_FOCUS.md) 为准；上表只描述 UI 对应的动作。

- 排序：热门/最新，chip 在 tab 内右上。

### 7.2 相关推荐

- 单列 72dp 行：缩略图 112×63 + 标题 2 行 + UP/播放量。
- 首屏 5 行；滚动加载 20 条。
- A 播放并替换当前视频（先上报进度、再切换）；B 不返回。

- 统计行（播放/弹幕/点赞）+ 简介全文，最多 4 行，可滚动；`#标签` 用 `blue`
  可点击（进入搜索）。

- 操作行：收藏 / 下载两个等宽按钮；**关注不在操作行重复**。
- BV 号 + 复制。
- 尺寸、焦点顺序和登录引导见 §5。

### 7.4 分P

- 列表行 48dp：`P1  标题`，当前项粉色竖条 + `pink` 文字。
- 20 个以上分P时顶部显示「共 N P」+ 当前序号。

## 14. 触摸与焦点（页面级补充）

- 触摸任何可点元素：先设焦点，再执行点击；焦点环留在被点元素上，手柄从那里继续。
- 触摸滚动：只滚动，不改变焦点；除非用户点击了某个卡片。
- `TOP_PLAYER` 下触摸：只切 `BOTTOM_UI` + 聚焦，不执行点击；第二次触摸才执行。
- 从列表进入播放：焦点默认在「播放/暂停」；若从相关推荐切换视频，保留当前 tab 焦点。
- 返回时恢复该页面上次焦点；页面被销毁后回到第一个可聚焦项。
- 列表滚动必须把焦点项带到可视区（`BringIntoViewRequester`），不能出现焦点在屏幕外。
