# bili-duo 输入与焦点规范 v0.3

> 这是本项目的输入契约：**任意时刻只有一个输入所有者、一棵下屏焦点树。**
> 禁止恢复旧 wiliwili 双屏「所有按键无条件转发 + 上屏隐藏 OSD」的模型。
> 2026-11-04 已删除旧的 `TOP_PLAYER ↔ BOTTOM_UI` 双模式与 Y 切换。
> 相关页面布局见 [`SCREEN_SPEC.md`](SCREEN_SPEC.md)，视觉见
> [`DESIGN_SYSTEM.md`](DESIGN_SYSTEM.md)。

## 1. 模式

| 模式 | 谁消费输入 | 何时进入 |
|---|---|---|
| `BROWSE` | 下屏 Compose 焦点树 | 首页/搜索/历史/收藏等无播放页 |
| `PLAYER` | 下屏 Compose 焦点树 | 视频/直播控制台进入后 |
| `OVERLAY` | 下屏 modal | 清晰度/倍速/弹幕设置/发送/图片等 |

- 播放中没有“控视频/控界面”之分；D-pad、A、X、START、LB/RB 全部进入同一棵
  焦点树。
- 进入 `PLAYER` 默认聚焦播放/暂停键；playurl 加载期间该键也保持可聚焦。
- `OVERLAY` 打开时独占输入；B 只关闭 overlay，不退出播放。
- 没有 Y 模式切换，也没有“第一次触摸只切模式”的中间态。

## 2. 键位

### 2.1 视频控制台（`PLAYER`）

| 输入 | 行为 |
|---|---|
| D-pad | 移动焦点；进度条聚焦时左右 seek 10s |
| A | 激活焦点：播放/暂停、±10s、清晰度/倍速/弹幕/字幕/音量、tab、评论操作 |
| B | 关 overlay → 右栏回播放键 → 左栏根退出播放 |
| X | 弹幕开/关（全局） |
| START / MENU | 打开清晰度菜单 |
| LB / RB | 切换右栏 tab（评论/推荐/简介/分P） |
| Y | 不绑定 |
| 触摸 | 一次点击直接操作 |

### 2.2 直播控制台（`PLAYER`）

| 输入 | 行为 |
|---|---|
| D-pad | 移动焦点 |
| A | 激活焦点：播放/刷新/回到直播/清晰度/音量/关注/发送 |
| B | 关 overlay/键盘 → 右栏回播放键 → 左栏根退出直播 |
| START / MENU | 打开清晰度菜单 |
| LB / RB | 切换右栏 tab（直播评论/直播信息） |
| X / Y | 不绑定 |
| 触摸 | 一次点击直接操作 |

### 2.3 浏览页（`BROWSE`）

| 输入 | 行为 |
|---|---|
| D-pad | 移动焦点；列表/网格滚动 |
| A | 确认/播放/打开 |
| B | 关闭页面内确认层 → 返回上一页 |
| X | 页面上下文操作 |
| Y | 搜索页切排序；其他页面无绑定 |
| L1 / R1 | 切一级 tab：首页 直播/推荐/热门/排行/番剧/影视；动态 全部/视频/图文；UP 主空间 视频/合集 |
| L2 / R2 | 切二级筛选行：直播分区、动态 UP 主、搜索排序（L2 上一个 / R2 下一个） |
| START | 页面菜单（如有） |

### 2.4 Overlay

| 输入 | 行为 |
|---|---|
| D-pad | 在 overlay 内移动焦点 |
| A | 选中/切换 |
| B | 关闭 overlay，焦点回打开它的控件 |
| Y | 不绑定；不允许越过 overlay 切模式 |

## 3. B 的焦点层级

`InputRouter` 只把 B 变成 `requestBack()`，具体优先级：

1. `setBackInterceptor`：页面级确认层、直播输入框（收键盘）等。
2. `setFocusBackInterceptor`：播放器右栏有焦点时，回到播放/暂停键。
3. `NavHost.popBackStack()`：播放器左栏根退出，或浏览页返回。

因此：
- 直播评论输入框：第一次 B 收键盘并回播放键，不会直接退出直播。
- 播放器右栏 tab/评论：B 回播放键；再按 B 才退出。
- 播放器左栏任意控件：B 直接退出播放。

## 4. 焦点与视觉

- 焦点环：内容外 4dp 空隙 + 1.5dp 白环 + 3.5dp 深色边；必须放在 `clip` 之前。
- 滚动列表需要 7dp 透明焦点余量；比视口高的卡片要显式 `scrollToItem`。
- 播放键聚焦时显示白色圆环；进度条聚焦时显示外框。
- 所有可聚焦控件用 `duoClickable`（focusable + A/Enter 激活）。
- 单行输入框加 `duoTextFieldNavigation()`，让 Up/Down 交还焦点管理器。

## 5. 去重与重复

- 同 keyCode 40ms 窗口去重；A/B 忽略 repeat。
- 方向键 repeat 在 `InputRouter` 被吞掉，长按只移动一格；L1/R1/L2/R2 同样只处理
  首次按下，长按不会连续跳 tab。进度条上的重复 seek 由控制台自己处理
  （当前每次按键 10s，不依赖系统 repeat）。
- 触摸一次点击直接聚焦并激活，不吞第一次按下。

## 6. 模式条

- 浏览：`浏览 · 手柄/触屏` + `B 返回` + `A 确认`
- 播放：`播放控制 · 手柄/触屏` + `B 返回` + `A 确认 · START 菜单`
- Overlay：`菜单` + `B 关闭 · 方向键选择` + `A 确认`
- 没有 Y 提示；没有可点击的“切换模式”区域。
