安装说明

  1. 下载 release APK。
  2. 首次安装时，在系统设置中允许 Bili-Duo 安装未知应用。
  3. 覆盖安装会保留登录、设置和观看历史；从 debug 包换到 release 包需要先卸载。

适用设备

Retroid Pocket Duo、AYN Thor 等上下双屏 Android 掌机，需要 Android 7.0 或更高版本。

非 B 站官方客户端。问题反馈请到 GitHub Issues。
